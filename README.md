# Calci - Java Scientific Calculator

Calci is a Java-based scientific calculator developed using Eclipse IDE and Java Swing.

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication and division
- Trigonometric functions
- Logarithm
- Square root
- Power
- Percentage
- Parentheses support
- Graphical User Interface (GUI)

## Technologies Used

- Java
- Java Swing
- Eclipse IDE
